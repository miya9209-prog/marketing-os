# MISHARP 광고문구 자동생성기

## 실행
streamlit run app.py

## 필요 설정
- `OPENAI_API_KEY` 환경변수 또는 Streamlit Secrets에 설정
- 선택사항: `OPENAI_MODEL` (기본값: gpt-4.1-mini)

## 포함 기능
- 초기화 / 작업 저장 / 작업 불러오기 / 이미지추출 / URL 단축
- 상품 URL / 상품내용 / 이벤트 주요내용 입력
- 이미지 + 동영상 업로드
- SMS / 앱푸시 / 동영상 원고 / 인스타 릴스 / 틱톡 / 유튜브 쇼츠 / 카카오스타일 / REVIEW 생성
- 개인정보처리방침 / 서비스약관 별도 페이지
