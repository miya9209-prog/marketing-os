# MISHARP MARKETING OS

미샵 전용 광고문구 자동생성기 1차 앱입니다.

## 이번 수정 반영
- 개인정보 처리지침 / 서비스 약관 기본 내용 추가
- 상단 여백 확대 및 잘림 느낌 보정
- 버튼 배열 정리
  - 초기화 / 작업 저장 / 작업 불러오기 / 이미지추출 / URL 단축
- 이미지뿐 아니라 동영상 업로드 지원
  - 동영상은 대표 프레임을 추출해 분석에 활용
- 입력칸 분리
  - 상품내용
  - 이벤트 주요내용
- 출력 채널 추가/정리
  - SMS문자(단문,장문)
  - 앱푸시
  - 동영상 원고
  - 인스타 릴스 피드
  - 틱톡 피드
  - 유튜브 쇼츠 피드
  - 카카오스타일
  - REVIEW
- SMS 단문 규칙 보정
  - `(광고)미샵♥` 고정 시작
  - 괄호 유지
  - 하트 뒤 공백 금지
  - 55자 이내 후처리 강제
- 작업 저장 파일명 자동 개선
  - 상품명 또는 URL 기반 + 저장 시각 포함

## 저장 관련 주의
브라우저 기반 Streamlit 앱은 보안상 사용자의 PC 다운로드 폴더 안에 새 폴더를 자동 생성하거나,
특정 로컬 폴더로 강제 저장하는 기능을 일반적으로 지원하지 않습니다.
대신 저장 파일명을 자동으로 구분되게 만들어 작업 관리가 쉽도록 처리했습니다.

예시:
- `misharp_marketing_os_상품명_20260323_163000.json`

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 필수 설정
OpenAI API 키를 아래 둘 중 하나로 설정하세요.
- Streamlit secrets: `OPENAI_API_KEY`
- 환경변수: `OPENAI_API_KEY`
